# Development tools

Use `make test ARGS="<pytest args>"` to run tests, e.g. `make test ARGS="./tests/metrics/deepeval/"` to run only DeepEval metrics tests.
Use `make lint` to run linters and `make format` to run code formatters.

If you need to read the code of a library already used in the project, prefer to look for it in .venv/Lib/site-packages.
